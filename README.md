# stackdrop.it

Silent multi-app installer builder and portfolio hub for [stackdrop.it](https://stackdrop.it).

Pick apps, generate a single silent installer, and browse demos hosted from the same Express app.

**Live:** https://stackdrop.it  
**Stack:** Node.js, Express, EJS

Scrubbed nginx site configs live under `deploy/nginx/`. Copy `.env.example` to `.env` for local secrets.
