# Security Policy
# We take security seriously at Stackdrop. If you discover a security vulnerability,
# please report it responsibly through our feedback system.

# Scope
# This security policy applies to:
# - https://stackdrop.it/ and all subdomains
# - Stackdrop Pro dashboard
# - All associated APIs and services

# Out of Scope
# - Third-party services and dependencies
# - Social engineering attacks
# - Physical attacks
# - Denial of service attacks

# Reporting Process
# 1. Report the vulnerability through https://stackdrop.it/feedback
# 2. Provide detailed information about the vulnerability
# 3. Allow reasonable time for response and remediation
# 4. Do not publicly disclose until we've had a chance to fix it

# Response Timeline
# - Initial response: 24-48 hours
# - Status update: Within 1 week
# - Resolution: Depends on severity and complexity

# Recognition
# We appreciate responsible disclosure and will acknowledge security researchers
# who help us improve our security posture.

# Legal
# By reporting vulnerabilities, you agree to:
# - Not access or modify data that doesn't belong to you
# - Not disrupt our services
# - Not publicly disclose the vulnerability until we've had time to fix it
# - Comply with applicable laws and regulations
